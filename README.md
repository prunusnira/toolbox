# TOOLBOX

### by Nira

---

## What is this?

- This is a collection of tools and utilities designed to streamline various tasks and enhance productivity.
- Features will be added and hosted through https://tools.nira.one

## Features List

- Dev Tools
  - JSON Editor
  - Markdown Editor
  - Regex Playground
  - JWT Decoder
  - URL Encoder / Decoder
  - Timestamp Converter
  - Diff Viewer
  - JSON YAML Converter
  - Empty Line Cleaner

- Visual Tools
  - RGB/RGBA/HSV Color Converter
  - CSS Gradient Builder
  - Box Shadow Generator
  - Border Radius Generator
  - SVG Optimizer / Previewer
  - Palette Generator
